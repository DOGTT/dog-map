🐶 狗狗友好色卡（HEX值）​​
​​1. 高对比度蓝色系​​
​​亮眼蓝​​： #4A90E2  （类似天空蓝，户外易识别）
​​钴蓝​​： #0057B7 （深蓝色，适合背景或按钮）
​​电光蓝​​： #1DA1F2 （活泼醒目，适合互动元素）
​​2. 明快黄色系​​
​​柠檬黄​​： #FFD700  （高饱和，吸引注意力）
​​荧光黄​​： #FFFF00（夜间/弱光下更显眼）
​​琥珀黄​​： #FFBF00  （柔和但足够鲜明）
​​3. 安全辅助色​​
​​浅灰白​​： #F5F5F5（背景色，避免刺眼）
​​深灰黑​​： #333333（文字/边框，与亮色对比）
​​🎨 配色组合建议​​
​​方案1：活力蓝黄（适合游戏/互动）​​
主色： #4A90E2（按钮） + #FFD700 （高亮提示）
背景： #F5F5F5
文字： #333333
​​方案2：夜间模式（低光环境）​​
主色：  #1DA1F2（蓝） + #FFFF00（荧光黄）
背景：  #121212（深灰）
​​方案3：柔和友好（宠物健康类应用）​​
主色： #0057B7 （稳重蓝） + #FFBF00 （温和黄）
辅助色： #A0D8FF （浅蓝点缀）
​​⚠️ 避雷色号​​
红色系： #FF0000（狗狗眼中近似灰褐）
绿色系： #00FF00（可能显灰白）
粉紫色： #FFC0CB（低对比度）
